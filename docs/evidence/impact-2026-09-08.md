# The book with Abadi in it, and without

469 orders this project has rested, across 148 windows.

## Spread at the moment Abadi's quote landed

| | windows | mean spread | in ticks |
|---|---|---|---|
| the book as it was | 148 | 0.0245 | 24.5 |
| the book with Abadi in it | 148 | 0.0175 | 17.5 |
| **difference** | | **-0.0069** | **-6.9** |

Abadi tightened the book on **138 of 148** windows, left it unchanged on 10, and widened it on 0.

Widening is not a failure mode here and it is left in rather than filtered out: a
quote resting outside the incumbent's touch does not move the touch, and a maker
that only ever quoted inside would be a maker that never quoted when the spread was
already tight.
